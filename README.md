# 声学超材料设计与验证一体化平台 · 纯前端交互原型

本项目依据《声学超材料平台_系统页面设计说明 V1.2》制作，为无后端依赖的浏览器可交互原型。

## 直接预览

克隆仓库后双击 `index.html` 即可打开。为避免部分浏览器对 `file://` 的限制，也可以在仓库目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 原型体验账号

- 管理员：`admin / 123456`
- 普通用户：`user / 123456`
- 待审核用户：`pending / 123456`
- 短信验证码演示值：`888888`

## 已覆盖页面

用户端：登录、注册、找回密码、首页、仿真数据查询、正向预测、逆向设计、文献问答、修改密码。

管理后台：数据库管理、知识库管理、用户管理、权限管理、系统日志。

## 说明

1. 文档标注“待确认”的正向预测字段、导出文件格式、target 曲线来源、联网边界等均以显式提示或原型占位实现，没有擅自固化为正式开发口径。
2. 页面插图统一来自附件素材，已作为 SVG Data URL 内嵌到前端资源中，仓库无需额外图片依赖即可离线运行。
3. 异步计算、知识库解析、问答流式输出、下载、审核、删除、角色变更等均为浏览器本地模拟；数据保存在 `localStorage`。
4. 无外部 CDN、字体或 JS 依赖，可离线预览。
